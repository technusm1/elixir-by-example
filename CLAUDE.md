# CLAUDE.md: elixirbyexample.com

Static site generated by a small Elixir app (`lib/ebe`), served by a Cloudflare Worker with static assets, analytics in D1. See README.md for commands and layout.

## Hard rules

- **Examples must be verified, never hand-written output.** Output on pages comes only from running the `.exs` on the pinned toolchain. Never paste output into prose without checking the real output. Prose claims must match what actually prints (real output has already disproved several "well-known" facts).
- **Toolchain is pinned in `.tool-versions`** (latest stable Elixir/OTP). The runner uses the build VM's own `elixir`/`erl` binaries, and `Runner.check_toolchain!/0` enforces it. Don't call `elixir` from PATH in build code (asdf shims resolve per directory).
- **Every example must also pass in the browser** (`npm run verify:browser`). If it can't run there, set `no_run:` in the catalog with a reader-facing reason. Don't add entries to `tools/browser-diffs.json` without a real runtime difference to explain.
- **Determinism:** no pids, refs, timings or races in output. Silence intentional crash logs (`Logger.configure(level: :none)`) and say why in prose.
- **Single-file script gotchas:** a struct literal `%Mod{}` or `import Mod` at top level of the same file that defines `Mod` fails to compile. Use constructors/`struct!/2`/aliases. Don't name modules after stdlib ones (`Config`, `Registry`, `Logger`...).
- **Compile-time safety:** `warnings_as_errors` everywhere, catalog checked at compile time, HEEx templates with `attr`. `mix check` must pass: format, compile, credo --strict, dialyzer, test, build.
- **Page weight:** no third-party scripts, fonts or CSS. JS only for the Run button (`priv/static/run.js`); Popcorn (~4 MB brotli) loads only on first Run click.
- **Privacy:** no cookies, no IPs, no visitor ids. The Worker stores path, client class (human/agent/tool/crawler), agent name, referrer host, country, device class.
- **Don't change URLs** (`/<track>/<slug>`, `/<track>/<project>-<step>`, `.exs` twins, `/llms.txt`, `/llms-full.txt`). Old Jekyll URLs redirect in `worker/index.js`.
- Owner preferences: imports at top of files, never inside functions. No Claude/AI attribution in commits. DNS changes in Cloudflare are done by the owner.
- Drive the cmux browser with `cmux browser --surface <ref> …` (goto, snapshot, click, eval).
